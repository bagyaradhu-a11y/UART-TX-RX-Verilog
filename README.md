# UART TX/RX using Verilog

This project focuses on designing a UART communication system using Verilog HDL.

## Current Progress

* UART Transmitter implemented
* Baud rate timing implemented using clock counters
* Start bit, 8-bit data transmission, and stop bit handling completed
* Transmitter functionality verified using simulation

## In Progress

* UART Receiver design
* Complete TX-RX integration
* Final verification

## Tools Used

* Verilog HDL
* Xilinx Vivado

## Project Structure

* `rtl/` – Verilog source files
* `tb/` – Testbench files
* `docs/` – Simulation waveforms and reports

## Status

Ongoing – UART Transmitter completed, Receiver yet to be implemented.
